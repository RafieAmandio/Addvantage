Plain pandoc markdown-to-docx output is not acceptable. User called it "ass."

**Why:** The default pandoc docx has no styling, no cover page, no branding — looks unprofessional.

**How to apply:** When generating docx documents, use a custom reference template with proper styling, cover pages, headers/footers, and professional formatting. Never ship a bare pandoc conversion.
